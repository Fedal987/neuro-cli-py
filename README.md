## 介绍

Neuro-CLI 是一个基于大语言模型的可以与系统交互的Agent应用。

Neuro-CLI 不仅仅是一个聊天机器人，它还是一个非常有用(迫真)的工具，其最终目的是实现类似于OpenClaw的系统交互应用
